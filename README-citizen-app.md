# 📲 नागरिक ॲप (माझी ग्रामपंचायत) — सेटअप

हे ॲप PWA आहे: कोणत्याही HTTPS होस्टिंगवर (उदा. GitHub Pages) `citizen-app` फोल्डर ठेवा. फोनच्या Chrome मध्ये उघडून "Install app / होम स्क्रीनवर जोडा". (APK हवा असल्यास हेच फोल्डर नंतर Capacitor मध्ये गुंडाळता येते.)

## ग्रामपंचायतीने एकदा करायचे (सॉफ्टवेअरमध्ये)
1. Firebase मध्ये **Authentication → Email/Password** सुरू ठेवा (आधीच Cloud Sync साठी असेल).
2. Masters → Firebase नियम (Rules) — सॉफ्टवेअरमधील "Rules कॉपी" बटण वापरा आणि Firebase → Firestore → Rules मध्ये पेस्ट करून Publish करा. नियमांतील `ADMIN_EMAIL` ऐवजी तुमचा Sync-Sign-in ईमेल आपोआप भरला जातो (कॉपी करताना). **जुने नियम बदलणे आवश्यक.**
3. Masters → "📲 नागरिक ॲप": गाव निवडा, दाखला शुल्क भरा, UPI ID (ऐच्छिक), "ग्रामनिधी (घरपट्टी) QR", "अधिकारी स्वाक्षरी" व "शिक्का" अपलोड करा → Masters जतन → **ॲप माहिती प्रकाशित करा**.
4. "ॲप नोंदणी तपशील कॉपी करा" दाबून मिळणारी ओळ `citizen-app/directory.json` च्या `"gps"` यादीत जोडा. (गाव-यादी `directory` मध्येही असावी.)
5. वेबसाईट प्रकाशित केलेली असेल तर ती ॲपमध्ये "वेबसाईट" टॅबमध्ये दिसते.

## मागणी क्रमांक व जुळवणी
- प्रत्येक मागणीला क्रमांक मिळतो: दाखले `Dakhala0001, 0002…`, कर `Tax0001, 0002…`. नागरिकाला UPI ॲपच्या टीपेत (Remarks) हा क्रमांक लिहायला सांगितले जाते ("UPI ॲपमध्ये भरा" बटणात तो आपोआप भरतो; ग्रामपंचायतीचा UPI ID Masters मध्ये भरलेला असावा).
- "ॲप दाखले" टॅबमध्ये बँक स्टेटमेंट (Excel/CSV) निवडा: क्रमांक किंवा UTR आणि रक्कम जुळल्यास "जुळले" दिसते → "जुळलेले सर्व मंजूर करा". रक्कम/UTR न जुळणारे लिपिकाकडे तपासणीसाठी राहतात.

## रोजचे काम
- सॉफ्टवेअरमध्ये **📲 ॲप दाखले** → "यादी आणा" → UTR/स्क्रीनशॉट वरून खात्यात पैसे आल्याचे तपासा → **✅ मंजूर**.
  - दाखला: दाखला क्रमांक घेतला जातो, सही + शिक्का + QR सह दाखला तयार होऊन नागरिकाला ॲपमध्ये डाउनलोडसाठी मिळतो.
  - कर भरणा: अ.क्र./मिळकत क्रमांकावरून नमुना ९ मध्ये शोध; रक्कम आधी थकबाकी मग चालू कराला वाटली जाते; नमुना १० ला पावती नोंदते.

## गाव-डिरेक्टरी (राज्य → जिल्हा → तालुका → गाव)
नागरिक ॲपमध्ये **महाराष्ट्राची संपूर्ण LGD शासकीय यादी** आधीच आहे (36 जिल्हे, 358 तालुके, 44,930 गावे). प्रत्येक नाव **"English — मराठी"** असे दिसते. निवड: राज्य → जिल्हा → तालुका → गाव.

फाईल्स (सर्व `citizen-app` फोल्डरसोबत होस्ट करा):
- `directory-index.json` — राज्य/जिल्हा/तालुका यादी (लहान, २२ KB)
- `dir/27_<जिल्हा-कोड>.json` — त्या जिल्ह्याची गावे (जिल्हा निवडल्यावरच लोड होतात; सुमारे ५० KB)
- `directory.json` — फक्त **तुमच्या सुरू असलेल्या ग्रामपंचायतींची `gps` यादी** (खाली)

```
{"directory":{},
 "gps":[{"s":"महाराष्ट्र","d":"सोलापूर","t":"माढा","v":"वरवडे","p":"firebase-project-id","k":"web-api-key","w":"https://वेबसाईट"}]}
```
- `gps` मधील s/d/t/v **मराठी नावे** असावीत (सॉफ्टवेअरमधील "ॲप नोंदणी तपशील कॉपी करा" तीच देते).
- `gps` मध्ये नसलेले गाव नागरिकांना "ॲप अजून सुरू नाही" असे दाखवते.
- यादीत नसलेले गाव/राज्य हवे असल्यास `directory.json` च्या `"directory"` मध्ये `{"राज्य":{"जिल्हा":{"तालुका":["गाव"]}}}` असे जोडा.
- इतर राज्यांसाठी: lgdirectory.gov.in वरून त्या राज्याचे District/Subdistrict/Village xls डाउनलोड करून मला द्या — त्याच पद्धतीने जोडता येईल.

## मर्यादा (प्रामाणिकपणे)
- सही+शिक्का+QR पडताळणी = डिजिटल प्रतिमा; कायदेशीर DSC (Digital Signature Certificate) नाही.
- भरणा आपोआप जुळत नाही — लिपिक स्वतः तपासून मंजूर करतो.
- प्रत्यक्ष Firebase वर चाचणी तुम्ही करायची आहे (येथे बनावट सर्व्हरवर पूर्ण चाचणी झाली).

## 📢 सूचना / 🚨 आणीबाणी संदेश (नवीन)
- **सॉफ्टवेअर:** 📲 ॲप दाखले → **📢 सूचना** टॅब. वरच्या पेटीत सामान्य सूचना, खालच्या लाल पेटीत **🚨 आणीबाणी संदेश** लिहून पाठवा. पाठवलेल्या सूचना यादीत दिसतात; **🗑️ काढा** ने ॲपमधूनही निघतात.
- **नागरिक ॲप:** नवा **📢 सूचना** टॅब (न वाचलेल्यांची लाल संख्या). सामान्य सूचना → वर बॅनर + नोटिफिकेशन. आणीबाणी → पूर्ण लाल स्क्रीन, **सायरन + कंपन**; **🔊 ऐका** दाबल्यावर मराठीत मोठ्याने वाचते (सायरन बंद होतो).
- गावातील **सर्व लॉगिन नागरिकांना** एकाच वेळी जाते (सर्व एकच `gpapp/notices` वाचतात). **Firebase Rules बदलण्याची गरज नाही.**
- **ॲप बंद असतानाही (FCM push):** सॉफ्टवेअर संदेश पाठवताना रिले (Cloud Function) मार्फत FCM topic `gp_<Firebase project id>` ला push जातो; आणीबाणीला सायरन-आवाजाचे चॅनेल (`gp-alarm`) वापरले जाते. एकदाचे सेटअप: `push-relay/README-मराठी.md`. सेटअप नसेल तर ॲप उघडे असताना (दर २० सेकंदांनी तपासणी) सूचना चालतात.
- सायरनचा आवाज फोनच्या व्हॉल्यूम/सायलेंट सेटिंगवर अवलंबून आहे; ॲप स्वतः फोनचा व्हॉल्यूम वाढवू शकत नाही. सायलेंट/DND मध्येही वाजण्यासाठी फोनच्या सेटिंगमध्ये ॲपचे "आणीबाणी सूचना (सायरन)" चॅनेल → "Override Do Not Disturb" चालू करा. मराठी वाचनासाठी फोनमध्ये Google Text-to-Speech चा मराठी आवाज असावा (नसल्यास हिंदी आवाज वापरतो).
